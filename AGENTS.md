## Project layout

- `AGENTS.md`, `spec.md`, `prompts.md`, and `index.html` belong at the project root. Keep `index.html` at the root for GitHub Pages.
- `00_planning/` is for planning notes and sketches.
- `01_data/` is for data files.
- `02_validation/` is for hand calculations and test cases.
- `03_output/` is for screenshots and exported results.

Save every new file in the root or numbered folder that best matches its purpose. Keep the root `index.html` as the single-file web app entry point; do not scatter app files into the numbered folders.
